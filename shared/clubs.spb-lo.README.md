# Справочник бильярдных клубов Санкт-Петербурга и Ленинградской области

Файл `clubs.spb-lo.json` — плоский JSON-массив клубов, где играют в русский бильярд
(12ft столы, 68 мм шары). Загружается backend seed-скриптом
(`backend/src/seed/seed-clubs.js`, вызывается через `npm run db:seed`).

Формат каждой записи:

```json
{
  "name": "Название",
  "address": "Полный адрес",
  "lat": 59.9311,
  "lon": 30.3609,
  "city": "Санкт-Петербург" | "Ленинградская область",
  "_note": "опциональный комментарий (например, о точности координат)"
}
```

## Геокодинг

Координаты `lat`/`lon` получены через OpenStreetMap Nominatim
(<https://nominatim.openstreetmap.org/>) по адресам из справочников.
Точность — обычно уровень здания (±10-30 м), для торговых центров
и крупных комплексов — до ±50 м. Записи с ощутимой погрешностью
или альтернативным источником помечены полем `_note`.

## Проверка / обновление

Перед коммитом добавьте/измените запись в JSON и убедитесь, что:

- координаты СПб попадают в диапазон lat 59.7–60.1, lon 30.1–30.6;
- координаты ЛО правдоподобны (Выборг ≈ 60.7/28.75, Гатчина ≈ 59.57/30.13,
  Всеволожск ≈ 60.01/30.59, Кировск ≈ 59.88/30.98);
- клуб действительно предлагает русский бильярд (пул/снукер отдельно —
  не критерий отсева, но основной фокус — русская пирамида).

После правки — прогнать `npm run db:seed` в backend, чтобы проверить,
что скрипт распарсил файл и вставил новые клубы.
